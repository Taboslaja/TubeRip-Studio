# TubeRip Studio — 詳細ユーザーガイド

## 1. 概要と必要条件

TubeRip Studio は、音声・動画ファイルをダウンロード、変換、管理するローカル Web アプリです。画面はお使いの PC 上で動くサーバーと通信します。動画情報の取得とダウンロードにはインターネット接続が必要です。ダウンロードには yt-dlp、メディア変換には FFmpeg を使用します。ダウンロードが許可されているコンテンツのみを保存してください。付属ランチャーと FFmpeg 自動更新は Windows 向けです。ソースから実行する場合は Node.js も利用できます。

## 2. 起動と終了

アプリのフォルダー全体を展開し、Windows で `Inditas.bat` を実行します。ローカルサーバーが起動し、`http://localhost:3000` を開きます。使用中はコマンド画面を閉じないでください。閉じるとサーバーが停止します。ブラウザーが開かない場合は URL を入力してください。`dist/index.html` を直接開かないでください。開発時はプロジェクトフォルダーで `npm install`、続けて `npm run dev` を実行します。Windows ランチャーは `server.py` を使用します。標準ポートは 3000 です。

## 3. 言語、テーマ、保存先

言語選択は画面上部のヘッダーにあり、TubeRip Studio の名前とテーマ選択の近くに表示されます。ハンガリー語、英語、ドイツ語、フランス語、スペイン語、ロシア語、日本語、簡体字中国語を選べます。選択はこのブラウザーに保存されます。

4 種類のカラーテーマから選択します。「ダウンロードフォルダー」にパスを入力するか、「参照」から Windows のフォルダー選択画面を開きます。パスはブラウザーに保存されます。保存先には書き込み権限と十分な空き容量が必要です。

## 4. 1 本の動画または音声をダウンロード

1. **単体ダウンロード**を開き、YouTube 動画 URL を貼り付けます。利用可能な場合、タイトル、チャンネル、再生時間、サムネイルが自動で読み込まれます。
2. MP3、MP4、M4A、WAV を選びます。音声の品質はビットレート、動画の品質は解像度で選択します。
3. 必要に応じて詳細設定を開き、ファイル名を指定したり、音声タグとカバー画像の自動追加を有効にしたりします。変換とメタデータ埋め込みには FFmpeg が必要です。
4. ダウンロードを開始します。進行表示には処理段階、進捗率、速度、残り時間の目安が表示されます。完成ファイルは選択したフォルダーに保存されます。

プレイリスト URL は検出され、プレイリストタブに案内されます。単体ダウンロード欄では一度に 1 本を扱います。

## 5. プレイリストのダウンロード

**プレイリスト**を開いて URL を貼り付け、項目を読み込みます。一覧を確認し、必要な曲またはすべてを選択します。形式と品質を選びます。番号付けを有効にすると、曲順がファイル名に追加されます。ダウンロードを開始し、項目ごとの状態を確認します。完了したファイルは、選択したフォルダー内で 1 つの ZIP にまとめられます。

## 6. 一括ダウンロード

**一括ダウンロード**欄に複数の URL を 1 行ずつ貼り付けます。共通の形式と品質を選び、処理を開始します。キューに各 URL の状態と進捗が表示されます。項目を削除したり、完了したファイルを再生・保存したりできます。

## 7. ライブラリとプレーヤー

**ライブラリとプレーヤー**には、アプリが認識している出力フォルダー内のメディアが表示されます。一覧を更新し、音声または動画で絞り込み、音声を再生し、ブラウザー経由で保存し、または削除できます。削除前に確認が表示されます。画面下部の固定プレーヤーでは再生・一時停止、進捗確認、音量調整、閉じる操作ができます。

## 8. インストーラー、ガイド、FFmpeg 更新

**Windows インストーラー**ページでは、単体セットアップファイルとウィザードの説明を確認できます。インストーラー ZIP ボタンからパッケージとガイドを開きます。これらのツールは Windows へのローカルインストール用です。ソースから Web アプリを動かすには Python または Node.js 開発環境が必要です。

起動時に、ローカルサーバーは BtbN FFmpeg Builds の最新 Windows 版を確認します。この更新機能でまだインストールされていない版が見つかると、ダウンロード前に確認します。承認すると `ffmpeg.exe`、`ffprobe.exe`、`ffplay.exe` と関連 DLL をアプリのフォルダーへ保存します。確認にはインターネットが必要ですが、失敗しても他の機能は使えます。アプリのフォルダーに書き込み権限が必要です。更新を拒否した場合は現在の FFmpeg を使い続けます。

## 9. トラブルシューティング

- **ページが開かない:** `Inditas.bat` の画面が実行中か確認し、`http://localhost:3000` を開きます。ポート 3000 が使用中なら、そのアプリを終了してください。
- **言語選択が見えない、または古い画面:** `Ctrl+F5` で強制再読み込みします。Windows ランチャーは `dist/` のビルド済み画面を配信します。ソース変更後は `npm run build` が必要です。
- **URL の解析やダウンロードに失敗:** URL、ネット接続、サーバー画面のエラーを確認します。YouTube の制限により利用できない場合があります。
- **変換や MP3 作成に失敗:** FFmpeg と保存先の書き込み権限を確認します。更新が提示された場合はインストールしてください。
- **フォルダー選択が開かない:** パスを直接入力してください。Windows のネイティブダイアログには対話型デスクトップが必要です。
- **保存された設定を消す:** ブラウザーのサイトストレージから `tuberip-language` または `tuberip-download-dir` を削除します。

## 10. データと制限

画面は localhost サーバーを通じて動作します。言語と保存先はブラウザーに記録され、メディアは指定したローカルフォルダーに保存されます。メタデータ取得とダウンロードでは外部サービスに接続します。一部の動画、地域、アカウント制限付きコンテンツは利用できない場合があります。表示文言やパッケージ内容はバージョンごとに変わることがあります。
