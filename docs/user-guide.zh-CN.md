# TubeRip Studio — 详细使用指南

## 1. 用途与要求

TubeRip Studio 是一个在本机运行的网页应用，用于下载、转换和管理音频与视频文件。网页会连接到电脑上的本地服务器。获取视频信息和下载媒体需要互联网连接。下载由 yt-dlp 处理，媒体转换由 FFmpeg 处理。请只下载你有权保存的内容。随附启动器和 FFmpeg 自动更新功能面向 Windows；从源代码运行也可以使用 Node.js。

## 2. 启动与退出

解压完整程序文件夹，在 Windows 中运行 `Inditas.bat`。本地服务器启动后会打开 `http://localhost:3000`。使用期间请保持命令窗口开启；关闭窗口会停止服务器。如果浏览器没有自动打开，请手动输入地址。不要直接打开 `dist/index.html`。开发时，在项目目录运行 `npm install`，然后运行 `npm run dev`。Windows 启动器使用 `server.py`，默认端口为 3000。

## 3. 语言、主题和保存位置

语言选择器位于页面顶部标题栏，在 TubeRip Studio 名称和主题选择器附近。可选择匈牙利语、英语、德语、法语、西班牙语、俄语、日语和简体中文。语言选择保存在当前浏览器中。

可从四种配色主题中选择一种。在“下载文件夹”中输入路径，或点击“浏览”打开 Windows 文件夹选择器。路径会保存在浏览器中。目标文件夹必须可写，并有足够的可用空间。

## 4. 下载单个视频或音轨

1. 打开**单项下载**，粘贴 YouTube 视频网址。若信息可用，标题、频道、时长和缩略图会自动加载。
2. 选择 MP3、MP4、M4A 或 WAV。音频质量以比特率选择，视频质量以分辨率选择。
3. 需要时打开高级设置，自定义文件名，或启用自动写入音频标签和封面。转换和写入元数据需要 FFmpeg。
4. 开始下载。进度区域会显示处理阶段、百分比、速度和预计剩余时间。完成的文件会保存到所选文件夹。

检测到播放列表链接时，页面会提示转到播放列表标签。单项下载表单一次处理一个视频。

## 5. 下载播放列表

打开**播放列表**，粘贴播放列表网址并加载条目。检查列表后选择需要的曲目，或全选。选择格式和质量。可选编号会把播放顺序写入曲目文件名。开始下载后，可逐项查看状态。下载完成的文件可以打包成一个 ZIP，保存到所选文件夹。

## 6. 批量下载

在**批量下载**中粘贴多个网址，每行一个。选择统一的格式和质量，然后开始处理。队列会显示每个网址的状态和进度。可以移除队列项目；已完成的文件可以播放，也可以通过下载链接保存。

## 7. 媒体库和播放器

**媒体库和播放器**会列出应用已知输出文件夹中的媒体。刷新列表，按音频或视频筛选，播放音频，通过浏览器保存文件，或删除文件。删除前会要求确认。页面底部的固定播放器支持播放/暂停、查看进度、调节音量和关闭播放器。

## 8. 安装程序、帮助和 FFmpeg 更新

**Windows 安装程序**页面提供独立安装文件并说明安装向导。安装程序 ZIP 按钮会打开打包文件和安装指南。这些工具用于在 Windows 本机安装。若从源代码运行网页应用，需要 Python 或 Node.js 开发环境。

启动时，本地服务器会检查 BtbN FFmpeg Builds 的最新 Windows 版本。如果发现此更新器尚未安装的版本，网页会在下载前请求确认。确认后会将 `ffmpeg.exe`、`ffprobe.exe`、`ffplay.exe` 及其相关 DLL 下载到程序文件夹。检查需要联网；检查失败不会阻止其他功能。程序文件夹必须可写。若拒绝更新，继续使用当前 FFmpeg。

## 9. 故障排除

- **网页打不开：**确认 `Inditas.bat` 命令窗口仍在运行，然后访问 `http://localhost:3000`。若 3000 端口被占用，请关闭正在使用该端口的程序。
- **看不到语言选择器或仍显示旧界面：**按 `Ctrl+F5` 强制刷新。Windows 启动器提供 `dist/` 中的构建文件；修改源代码后需要运行 `npm run build`。
- **网址无法分析或下载：**检查网址、网络连接和服务器窗口中的错误。YouTube 限制可能导致部分内容不可访问。
- **转换或 MP3 输出失败：**检查 FFmpeg 是否存在，以及目标文件夹是否可写。若程序提示有 FFmpeg 更新，可选择安装。
- **文件夹选择器未打开：**手动输入路径；原生文件夹对话框需要交互式 Windows 桌面。
- **清除已保存的选项：**在浏览器的网站存储中删除 `tuberip-language` 或 `tuberip-download-dir`，然后重新选择。

## 10. 数据与限制

界面通过 localhost 服务器运行。语言和目标文件夹保存在浏览器中，媒体文件写入所选本地文件夹。获取元数据和下载时会访问外部服务。部分视频、地区内容或需要账户权限的内容可能不可用。界面文字和安装包内容可能随版本变化。
