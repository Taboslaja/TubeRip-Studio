# TubeRip Studio — подробное руководство

## 1. Назначение и требования

TubeRip Studio — локально размещаемый веб-интерфейс для загрузки, преобразования и управления аудио- и видеофайлами. Страница взаимодействует с сервером на вашем компьютере. Для получения сведений о видео и загрузки необходим интернет. Загрузки выполняет yt-dlp, преобразование — FFmpeg. Загружайте только материалы, которые разрешено сохранять. Встроенный запускатель и автоматическое обновление FFmpeg рассчитаны на Windows. Исходный проект можно запустить с Node.js.

## 2. Запуск и завершение работы

Распакуйте всю папку программы и запустите в Windows файл `Inditas.bat`. Он запускает локальный сервер и открывает `http://localhost:3000`. Оставьте окно командной строки открытым: его закрытие остановит сервер. Если браузер не открылся, введите адрес вручную. Не открывайте `dist/index.html` непосредственно. Для разработки выполните в папке проекта команды `npm install`, затем `npm run dev`. Запускатель Windows использует `server.py`; стандартный порт — 3000.

## 3. Язык, тема и папка сохранения

Выбор языка находится в верхней панели рядом с TubeRip Studio и выбором темы. Доступны венгерский, английский, немецкий, французский, испанский, русский, японский и упрощённый китайский. Выбранный язык сохраняется в браузере.

Выберите одну из четырёх цветовых тем. В поле папки загрузки введите путь или нажмите «Обзор», чтобы открыть диалог Windows. Путь сохраняется в браузере. Папка должна быть доступна для записи и иметь достаточно свободного места.

## 4. Загрузка одного видео или аудиодорожки

1. Откройте **Загрузка видео** и вставьте URL видео YouTube. Если сведения доступны, автоматически появятся название, канал, длительность и обложка.
2. Выберите MP3, MP4, M4A или WAV. Для аудио качество задаётся битрейтом, для видео — разрешением.
3. При необходимости откройте дополнительные настройки: задайте имя файла и включите автоматическое добавление аудиотегов и обложки. Для преобразования и встраивания метаданных нужен FFmpeg.
4. Запустите загрузку. Индикатор показывает этап, процент, скорость и примерное оставшееся время. Готовый файл появится в выбранной папке.

Ссылки на плейлист распознаются, после чего приложение предлагает вкладку плейлиста. Форма одиночной загрузки предназначена для одного видео.

## 5. Загрузка плейлиста

Откройте **Плейлист**, вставьте ссылку и загрузите список элементов. Просмотрите его, выберите нужные дорожки или отметьте все. Выберите формат и качество. При включении нумерации в имена файлов добавляется порядок дорожек. Запустите загрузку и следите за состоянием каждой записи. Готовые файлы можно объединить в ZIP-архив в выбранной папке.

## 6. Пакетная загрузка

Вставьте в **Пакетную загрузку** несколько ссылок, по одной на строку. Установите общий формат и качество и начните обработку. Очередь показывает состояние и прогресс каждой ссылки. Записи можно удалить; готовые файлы можно воспроизвести или сохранить по ссылке.

## 7. Медиатека и проигрыватель

Раздел **Медиатека и проигрыватель** показывает файлы в известных папках вывода. Обновите список, отфильтруйте аудио или видео, воспроизведите аудио, сохраните файл через браузер или удалите его. Перед удалением требуется подтверждение. Панель проигрывателя внизу страницы позволяет ставить воспроизведение на паузу, отслеживать прогресс, регулировать громкость и закрывать проигрыватель.

## 8. Установщик, справка и обновления FFmpeg

Страница **Установщик Windows** содержит файлы автономной установки и описание мастера. Кнопка ZIP установщика открывает пакет и руководство. Эти инструменты предназначены для локальной установки в Windows. Для запуска исходного веб-проекта требуется Python или среда разработки Node.js.

При запуске сервер проверяет последнюю сборку Windows в BtbN FFmpeg Builds. Если найдена версия, которую этот механизм ещё не устанавливал, интерфейс сначала запросит разрешение. После согласия в папку программы загружаются `ffmpeg.exe`, `ffprobe.exe`, `ffplay.exe` и связанные DLL. Проверка требует интернет; её сбой не отключает остальные функции. Папка программы должна быть доступна для записи. При отказе останется установленная версия FFmpeg.

## 9. Устранение неполадок

- **Страница не открывается:** убедитесь, что окно `Inditas.bat` всё ещё работает, затем откройте `http://localhost:3000`. Если порт 3000 занят, остановите приложение, которое его использует.
- **Не виден выбор языка или отображается старая страница:** обновите страницу сочетанием `Ctrl+F5`. Запускатель Windows обслуживает собранную папку `dist/`; после изменения исходников выполните `npm run build`.
- **Ссылка не анализируется или загрузка завершается ошибкой:** проверьте URL, подключение и сообщения сервера. Ограничения YouTube могут блокировать доступ.
- **Преобразование или MP3 не работают:** проверьте наличие FFmpeg и права записи в папку. Установите предложенное обновление FFmpeg.
- **Диалог папки не открывается:** введите путь вручную; системный диалог требует активного рабочего стола Windows.
- **Сбросить сохранённые параметры:** удалите `tuberip-language` или `tuberip-download-dir` из локального хранилища сайта в браузере.

## 10. Данные и ограничения

Интерфейс работает через localhost-сервер. Язык и папка сохраняются в браузере, медиафайлы записываются в выбранную локальную папку. Получение метаданных и загрузки обращаются к внешним службам. Некоторые видео, регионы или материалы с ограничением по учётной записи могут быть недоступны. Подписи и содержимое пакета меняются между версиями.
